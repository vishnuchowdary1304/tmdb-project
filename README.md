# 🎬 TMDB Movie Search

A JavaScript-based movie search application that uses **The Movie Database (TMDB) API** to fetch and display movie information dynamically.

## ✨ Features

* 🔍 Search for movies by title.
* 🎥 Retrieve movie information using the TMDB API.
* ⭐ Display movie ratings and other available details.
* 📅 Explore movie release dates and descriptions.
* ⚡ Fetch movie data dynamically through API requests.

## 🛠️ Technologies Used

* JavaScript
* TMDB API
* Node.js
* npm

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd tmdb-project
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure your API key

Obtain an API key from [The Movie Database (TMDB)](https://www.themoviedb.org/).

If your application requires an API key, store it in an environment variable rather than hardcoding it in your source code.

### 5. Run the project

Run the JavaScript file using Node.js:

```bash
node search.js
```
